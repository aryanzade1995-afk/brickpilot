# Villa exports for AutoCAD and SketchUp

On **3D Massing → Blender design**, use **Download 3D** or the villa's **Download Villa** menu:

- **AutoCAD 3D · building only / building + solar (.dxf)** opens as a 3D face mesh in AutoCAD. Drawing units are metres (`INSUNITS=6`); Z is up. Save as DWG in AutoCAD if needed.
- **SketchUp · building only / building + solar (.dae)** imports through File → Import → COLLADA in a supported SketchUp edition. Coordinates and asset units are metres with Z up. Keep Merge Coplanar Faces enabled to remove unnecessary triangle edges, then save as SKP in SketchUp. Use Zoom Extents if the model is initially outside the view.

These are actual 3D polygon meshes, not screenshots, floor plans, parametric solids or BIM elements. The accepted villa's evaluated geometry, object groups, placement and base colours are retained. Blender procedural shaders, image textures, lighting and camera scenes are not transferred. Native DWG and SKP files are not generated by Formstead. Import availability depends on the receiving application's edition.

The download label and filename identify its scope. A current **rendered** combined solar artifact supplies the accepted building and canonical PV geometry together. Without that artifact, export is explicitly building-only. Unsaved live solar drafts are never represented as applied geometry. Render the applied solar layout first to obtain a combined export.

The backend `GET /api/villas/:jobId/cad/dxf` or `/dae` reads that job's `accepted.json`, opens its saved `.blend` master, evaluates its meshes and writes both formats. It never runs the architectural generator, diversity search, panel allocator or renderer, and never saves over the accepted master. Conversions are deduplicated, serialized and published atomically. The cache includes exporter version, source path, size and modification time, plan, seed and solar cache identity. Failed conversions can be retried from the menu with an accessible error message.

Validation:

- `npm run test:villa-cad` checks cache reuse, concurrent formats, scope, invalidation, failure/retry, path validation and route handling.
- Run `scripts/test-villa-cad.py` inside Blender to verify evaluated modifiers, mirrored transforms, scale, elevations, PV, hidden exclusion and both file encodings.
