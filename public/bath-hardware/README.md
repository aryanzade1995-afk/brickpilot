# Detailed bathroom fittings

Local GLB models and editable Blender sources. No paid API or runtime download.
Created with `scripts/prepare-bath-hardware.py`.

Compact single basin mixers, overhead showers and the tap-free basin are original CC0 Blender geometry. Each basin has one compact mixer with red/blue indices, uniformly fitted to its footprint. Two separate low-level hot/cold taps are included below the shower for filling water.
The five shower sizes follow the existing catalogue's visual profiles. Sizes for
profiles without recorded dimensions remain illustrative. Curved necks, machined
collars, valve trim, hot/cold inserts, aerators, individual silicone jets and
recessed nozzle bores are modeled as geometry. Metallic parts can be recoloured
without changing rubber, ceramic or hot/cold indicators.

Models attach at the fitted basin rim or shower wall. A full assembly is never
scaled into the small placeholder spout. Shower and faucet assets use attachment
origins rather than the floor-centred origin used by general furniture assets.
Approximate nozzle detail is static; there are no running-water or water-use claims.

See LICENSE.txt and manifest.json for provenance and asset hashes.
