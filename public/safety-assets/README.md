# Fire extinguisher

Source: [Korean Fire Extinguisher 01](https://polyhaven.com/a/korean_fire_extinguisher_01)
Author: UM JOORIN / Poly Haven.
Licence: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Derived from the original Poly Haven 1K glTF and textures. Normalized in Blender
to 0.65 m tall with a centred, floor-level origin; embedded PBR textures and
original model geometry retained. The label is part of the original Korean asset.
The prop is a visual representation, not a specification of an approved fire
extinguisher or its required installation location.

`fire-extinguisher.blend` is the packed source used by the villa generator.
`fire-extinguisher.glb` is the browser asset used to upgrade legacy safety boxes.
Conversion script: `scripts/prepare-extinguisher.py`.
