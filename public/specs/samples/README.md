# Material sample visualisations

These are deterministic Blender renders, not installed-product photographs or AI images.
Generated by `blender/render_spec_samples.py`, using the same registered CC0 texture as
its corresponding catalogue close-up. They illustrate material appearance in a fixed
sample room, not the project geometry, supplier quality or slip performance.

Original textures and source licences: `blender/assets/LICENSES.md` and
`blender/assets/spec-materials.json`. File hashes, dimensions and captions:
`src/lib/cost/data/samples.json`. 1600 px originals and 800 px web copies are included.
Formstead sample scene and renders: CC0-1.0.
